# لهجتنا — frontend

React + TypeScript + Vite. See the root [`README.md`](../README.md) for setup/run
commands and [`DESIGN.md`](./DESIGN.md) for the visual design rationale.

```bash
npm install
npm run dev      # dev server on :5173, proxies /api to :8000 (see vite.config.ts)
npm run build    # -> dist/, served directly by the FastAPI backend at /
npm run lint
```
